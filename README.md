# RiceCare AI 

AI-powered Rice Leaf Disease Detection System using Deep Learning and Transfer Learning.

##  Features
- Detects rice leaf diseases
- Upload image prediction system
- Deep Learning based CNN model
- Streamlit Web Application
- Confidence score prediction

##  Diseases Detected
- Brown Spot
- Leaf Smut
- Bacterial Leaf Blight

##  Technologies Used
- Python
- TensorFlow
- MobileNetV2
- Streamlit
- OpenCV
- NumPy
- Matplotlib

##  Model Performance
- Training Accuracy: 92%
- Validation Accuracy: 82%
